## 🚀 Proyecto Destacado / Caso de Éxito

### **Orion SaaS — Sistema de Gestión Comercial, POS & Logística**
Actualmente me encuentro desarrollando **Orion**, una plataforma comercial moderna (SaaS) nacida como mi **Proyecto de Título** y propuesta interna para la cadena de retail **Cmoran**. 

* **El Desafío:** Rediseñar y optimizar procesos críticos de venta y auditoría de inventarios que tradicionalmente se realizaban de forma manual en papel y Excel (tomando hasta 2 días de trabajo continuo), además de automatizar la gestión estricta de cambios bajo políticas de retail.
* **La Solución:** Un ecosistema web y móvil interconectado via API con sistemas legados (Bsale), implementando escaneo móvil de códigos de barra, pre-cuadraturas automatizadas en tiempo real (reduciendo el proceso de 2 días a 2-3 horas), facturación electrónica con marca blanca y control anti-fraude para cambios de productos.
* **Stack:** React + Next.js, Tailwind CSS, API REST (Python/Django), PostgreSQL.
